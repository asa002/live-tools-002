### livetools002
This tool is designed for use during "endurance" (marathon-style) streams on various platforms. *Commercial use permitted.
You can set a target goal and up to six status categories, with the flexibility to add or subtract values ​​as needed.
The tool displays the difference between your target goal and the subtotal of your current status values.
It also includes save slots, making it easy to resume your progress in future sessions.
